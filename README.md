# Buzz人生シミュレーター

ランダムな国・家庭・時代に生まれ、SNSで発信しながら一生を生きる、ブラウザで遊べる人生シミュレーションゲームです（完成版 v4.0）。

**遊ぶ**：https://stella46.github.io/buzz-life/

- ブラウザで開くだけで遊べます。スマホは「ホーム画面に追加」でアプリのように使え、一度開けばオフラインでも遊べます。
- モードは2つ：**軽量**（現実の統計をもとに、人生を見守りながら分かれ道で選ぶ）／**通常**（SNS・お金・まち・会社・大計画・宇宙まで、すべて遊べるやりこみ向け）。
- 昔の版は、ゲーム内の「アップデート情報」→「昔の版で遊ぶ」から遊べます（`versions/`）。
- セーブデータや設定は、遊んでいるブラウザの中にだけ保存されます。

## 権利・出典
- 絵・音楽・効果音・文章は、すべてこのゲームのためのオリジナルです（絵と音はプログラムで生成）。
- 登場する国・地名・人物・SNS・企業・サービスは架空のものです（舞台「日本」「世界のどこか」の国名と、実際の出来事を除く）。
- 統計データの出典と、使用フォント（SIL Open Font License 1.1）は、ゲーム内の「設定・セーブ」→「クレジット」に記載しています。

## ソース
- `src/`：ゲームのソース（つなげて1つの index.html にします。手順は `src/BUILD.md`）
- `tools/`：過去の版の保存（archive_version.py）と自動テスト
- 感想・不具合の受付は終了しました。
